# Движок

Компонентный цикл на SFML 3. Игровой код собирает объекты из компонентов, движок их обновляет и рисует.

## Цикл

`Engine::Run` держит окно с вертикальной синхронизацией и лимитом 60 кадров. Кадр: события, `FixedUpdate`, отрисовка, `LateUpdate`.

Фиксированный шаг 0.02 с. Время кадра ограничено пятью шагами. На каждом шаге объекты получают `Update`, затем `PhysicsSystem`. `LateUpdate` удаляет объекты, помеченные на уничтожение.

Компоненты обновляются и рисуются в порядке добавления. Ось Y мира направлена вверх: высота камеры отрицательная, масштаб спрайта по Y тоже отрицательный.

## Физика

Коллайдеры задают AABB. Пара сталкивается, если слой каждого входит в маску другого. Два твёрдых тела раздвигаются по прямоугольнику пересечения. Два kinematic не двигаются. Если один из пары триггер, обоим один раз вызывается `OnTriggerEnter`, пока пересечение не пропадёт.

## Сетка

Клетка это пара индексов. Проходимые клетки передаются множеством.

`FindPathBFS` ищет путь в четыре стороны только по проходимым клеткам. Старт и цель, попавшие в стену, привязываются к ближайшей проходимой клетке по манхэттену. `GridPathLength` равна числу переходов, умноженному на размер клетки. `RandomGridCells` перемешивает проходимые клетки и возвращает нужное число разных. `GridCellCenter` переводит индекс в мировую позицию: индекс умножается на размер клетки.

## Погоня

`ChaseComponent` пишет оси для `MovementComponent`, поэтому его добавляют раньше движения.

Если прямая до цели длиннее радиуса, погоня останавливается. Иначе строится путь по сетке, и он тоже должен уложиться в радиус: так цель за стеной не считается видимой. Пока цель в той же клетке, движение идёт прямо на неё и прекращается ближе `stopDistance`.

На повороте точка маршрута сменяется только рядом с позицией клетки, с допуском 0.2 размера клетки. Если до точки смещены обе оси, сначала выравнивается меньшее смещение.

## Атака

`AttackComponent` требует конус и движение. `AttackTrigger::Input` начинает удар по нажатию пробела и на время удара фиксирует направление конуса. `AttackTrigger::Automatic` требует погоню и бьёт, когда цель погони внутри конуса.

`CalculateDamage` сейчас возвращает силу атаки. `StatsComponent::TakeDamage` вычитает броню, уменьшает броню на 1 и снимает оставшийся урон со здоровья. Конус в Debug рисуется полупрозрачным, проверка попадания работает и в Release.

## Прочее

`SpriteClipAnimatorComponent` хранит клипы по рядам листа: вниз, вверх, влево, вправо. Одноразовый клип сообщает кадр действия через `ConsumeAction`.

`ResourceSystem` загружает текстуры и карты кадров по имени. `Logger` пишет в консоль и в файл. Уровни: Info, Warning, Error.
