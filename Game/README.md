# Игра

Сцена `DeveloperLevel`. Ресурсы загружаются в `main` из папки `Resources` относительно рабочей папки процесса. Ею должен быть корень репозитория.

## Карта

Размер 16 на 16, клетка 128 пикселей. Граница с индексами 0 и 16 сплошная.

`MazeGenerator` строит проходы поиском в глубину. Комнаты стоят на нечётных клетках 1, 3, ..., 15. Из текущей комнаты выбирается случайный непосещённый сосед через одну клетку. Проходом становятся и сосед, и клетка между ними. Остальные внутренние клетки становятся стенами.

Спрайт стены выбирается по четырём соседям. Север это +Y. Маска N, E, S, W указывает кадр тайлсета `Wall.png`. Клетки за границей карты стенами не считаются. Пол ставится на внутренние проходы и на левую и правую границу.

## Персонажи

Четыре разные проходимые клетки выбираются через `RandomGridCells`. На первой появляется игрок, на остальных три вампира.

Игрок управляется с WASD, скорость 400. Пробел запускает удар конусом. Спрайт рыцаря: idle, run и Attack 1. Лист смотрит вправо, влево он отражается.

Вампир преследует игрока: радиус 3 клетки по длине пути, остановка на расстоянии 48. Скорость 450. `LocomotionAnimator` переключает idle и run и не трогает удар, пока играет одноразовая атака. Урон наносится автоматически, когда игрок в конусе.

## Монстры

`MonsterCatalog` по `MonsterId` выбирает фабрику. Сейчас зарегистрирован только вампир. `VampireFactory` при создании берёт случайную внешность из трёх листов: idle, run и attack. Неизвестный id выбрасывает исключение.
